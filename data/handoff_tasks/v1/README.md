# Hand-off tasks v1

`airline_tasks.json` and `retail_tasks.json` are generated on the cluster by
`bash slurm/submit.sh tasks` from the pinned τ²-bench data, hash-checked against
`data/manifests/handoff_tasks_v1.json` whenever they are loaded, and committed.
See [hand-off tasks](../../../docs/handoff-tasks.md).
